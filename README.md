# Matchstick Game (Streichholzspiel)

A two-player turn-based game played in the terminal. Start with 21 sticks;
each turn a player takes 1 to 3 sticks; whoever takes the last stick loses.

At the start you choose the starting sticks and the allowed range per move
(min and max), plus the mode: play against another person or against
the computer.

## Running

    node streichholz.js

Or with npm:

    npm start

Requires Node.js (installed via nvm). No dependencies.
