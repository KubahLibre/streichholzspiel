# Matchstick Game (Streichholzspiel)

A two-player turn-based game played in the terminal. Start with 21 sticks;
each turn a player takes 1 to 3 sticks; whoever takes the last stick loses.

At the start you choose the mode: play against another person or against
the computer. In computer mode you pick a difficulty — easy (random),
medium (50 % optimal) or hard (always optimal — Nim strategy).

## Running

    node streichholz.js

Or with npm:

    npm start

Requires Node.js (installed via nvm). No dependencies.
